# Table S6 reproducibility supplement

Copy the code, results, tables, verification and docs directories into the existing repository. No existing main-analysis file is replaced. After the analytical panel has been built using the repository's official retrieval workflow, run:

    python code/06_exposure_diagnostics.py

The accompanying code and aggregate outputs reproduce all five Table S6 rows at the manuscript's reported precision. See docs/S6_REPRODUCIBILITY.md for definitions, inference settings and validation. Provider observations and the analytical panel are not included.
