# Data access and redistribution

The frozen analysis uses three provider systems. Exact source filenames, access dates, official locations, units, and SHA-256 checksums are recorded in `../docs/DATA_SOURCE_MANIFEST.md`.

The public repository does not include `raw/imf-green-bonds-feature-query.json` or a derived analytical panel containing those provider observations unless redistribution permission is confirmed. Run `python code/00_download_sources.py` from the repository root to retrieve the public provider responses and test them against the frozen checksums. A checksum mismatch indicates source drift and must be reviewed before reproducing the locked estimates.

Files included under `raw/` remain subject to their source providers' terms. Files under `derived/` are generated by `code/01_build_panel.py`; they are not authoritative source records.
